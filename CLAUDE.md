# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Commands

Package manager is **pnpm** (see `pnpm-lock.yaml`).

- `pnpm dev` — start the Next.js dev server
- `pnpm build` — production build (`next build`)
- `pnpm start` — serve the production build
- `pnpm lint` — `eslint .` (no ESLint config is committed; running lint will use defaults / fail until one is added)

There is no test runner configured.

## Architecture

Next.js 16 App Router project (React 19, TypeScript) generated by **v0.app** (Vercel v0) and styled with Tailwind CSS v4 + shadcn/ui. The app is currently a single-page **demo / preview** of three unrelated screens, not a routed multi-page application.

- `app/layout.tsx` — root layout; forces `lang="es"`, dark theme (`<html className="dark bg-black">`), loads Montserrat via `next/font/google`, and conditionally mounts `@vercel/analytics` only in production.
- `app/page.tsx` — the only route. Holds a `useState<View>` with values `"landing" | "login" | "crm"` and renders one of three feature components. A fixed bottom pill nav (commented "Dev navigation - Only for preview") switches between them. There is no real auth, routing, or persistence — `LoginPage`'s `onLogin` simply flips state to `"crm"`.
- `components/` — three feature screens at the top level (`landing-page.tsx`, `login-page.tsx`, `crm-pipeline.tsx`) plus `theme-provider.tsx`. The CRM pipeline is built from a hard-coded `initialLeads` object in the file itself; there is no backend or data layer.
- `components/ui/` — shadcn/ui primitives ("new-york" style, neutral base, lucide icons). Configured in `components.json`. Add new primitives with `pnpm dlx shadcn@latest add <name>`.
- `lib/utils.ts` — only exports `cn()` (clsx + tailwind-merge). Use it for conditional class composition.
- `hooks/` — `use-mobile.ts`, `use-toast.ts` (note: shadcn copies of these also exist under `components/ui/`).
- `app/globals.css` is the active stylesheet (referenced by `components.json` and imported in `app/layout.tsx`). `styles/globals.css` exists but **differs** and is not imported — treat it as stale.

### Conventions to be aware of

- Path alias `@/*` → repo root (see `tsconfig.json`); shadcn aliases in `components.json` map `@/components`, `@/components/ui`, `@/lib`, `@/hooks`, `@/lib/utils`.
- `next.config.mjs` sets `typescript.ignoreBuildErrors: true` and `images.unoptimized: true`. Type errors will not block `pnpm build` — rely on editor diagnostics or `tsc --noEmit` if you need a real type check.
- The design language is dark-only with violet/fuchsia gradient accents; preserve this when adding screens (see existing `bg-black`, `from-violet-500 to-violet-700`, `shadow-[0_0_…_rgba(139,92,246,…)]` patterns).
- UI copy is in **Spanish**. The `metadata` in `app/layout.tsx` still says "Inmobiliaria CRM" but the actual content is a course/CRM demo for "Mirko Calzadilla" — update metadata if the project's identity is finalized.
